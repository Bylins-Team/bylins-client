# Что дальше

Клиент выпущен: [релизы](https://github.com/kvirund/bylins-client/releases),
сборки под Windows, Linux и macOS. Что уже умеет — в [README](README.md).

Живой список задач — [issues](https://github.com/kvirund/bylins-client/issues).
Здесь только крупное, до чего пока не дошли.

## Интерфейс
- Отдельные окна: вынос вкладки из главного окна, «поверх всех»
- Разделение окна по вертикали и горизонтали (сейчас есть только раздвоение
  прокрутки внутри одной вкладки)
- Уведомления о новых сообщениях в неактивных вкладках — сейчас только
  индикатор непрочитанного

## Скрипты и плагины
- Встроенный редактор скриптов
- Плагины не на JVM — сейчас плагин это Kotlin/Java, тогда как скрипты бывают
  на JavaScript, Python и Lua

## Распространение
- Автообновление
- Установщики msi и deb с плагинами. DMG их уже получает — он собирается из
  образа приложения, — а msi и deb собираются не из него, и всё положенное
  в их исходный каталог попадает в classpath: плагины перестают выгружаться
- Подпись и нотаризация для macOS: без них скачанное приложение попадает
  в карантин, и снимать его приходится вручную

## Разное
- SSL/TLS для telnet
- Импорт настроек из других клиентов (zMUD, MUSHclient)
